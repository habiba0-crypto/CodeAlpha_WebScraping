# CodeAlpha Web Scraping Project

## Project Overview
This project is completed as part of the CodeAlpha Data Analytics Internship.

The objective of this project is to collect book information from a public practice website using Python web scraping techniques.

## Website Used
https://books.toscrape.com/

## Tools and Libraries
- Python
- Google Colab
- Requests
- BeautifulSoup
- Pandas

## Data Collected
The following information was extracted:
- Book Title
- Price
- Rating
- Availability

## Project Tasks
1. Connected to the Books to Scrape website.
2. Extracted HTML content using Requests.
3. Parsed website data using BeautifulSoup.
4. Collected information from 50 pages.
5. Extracted data for 1000 books.
6. Converted prices and ratings into numeric formats.
7. Checked missing values and duplicate records.
8. Saved the cleaned dataset as a CSV file.

## Project Files
- CodeAlpha_WebScraping.ipynb – Python source code.
- CodeAlpha_WebScraping_Cleaned.csv – Cleaned dataset.

## Output
A structured dataset containing information about 1000 books.
